╔══════════════════════════════════════════════════════════════════════════════╗
║                   FP32 ↔ FP8 E4M3 Conversion Diagram                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────────┐
│                         FP32 Format (32 bits)                                │
├─────┬───────────────────────────┬───────────────────────────────────────────┤
│  S  │      Exponent (8 bits)    │         Mantissa (23 bits)                │
│ 1bit│         Bias = 127        │                                           │
└─────┴───────────────────────────┴───────────────────────────────────────────┘
  31                  30-23                        22-0

Example: 1.0 = 0 01111111 00000000000000000000000
         Sign=0, Exp=127, Mant=0 → (-1)^0 × 2^(127-127) × 1.0 = 1.0


                                   ↓ FP32 → FP8

┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 1: Extract FP32 Components                                             │
│   - Sign:     bit 31                                                        │
│   - Exponent: bits 30-23 (bias 127)                                         │
│   - Mantissa: bits 22-0  (23 bits)                                          │
└─────────────────────────────────────────────────────────────────────────────┘

                                       ↓

┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 2: Adjust Exponent Bias                                                │
│   exp_fp8 = exp_fp32 - 127 + 7                                              │
│                                                                              │
│   Example: 1.0                                                              │
│     exp_fp32 = 127                                                          │
│     exp_fp8  = 127 - 127 + 7 = 7                                            │
└─────────────────────────────────────────────────────────────────────────────┘

                                       ↓

┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 3: Round Mantissa (23 bits → 3 bits)                                   │
│   - Take top 3 bits of mantissa                                             │
│   - Round to nearest, ties to even                                          │
│                                                                              │
│   Example: 1.0                                                              │
│     mant_fp32 = 0b00000000000000000000000                                   │
│     mant_fp8  = 0b000 (top 3 bits)                                          │
└─────────────────────────────────────────────────────────────────────────────┘

                                       ↓

┌─────────────────────────────────────────────────────────────────────────────┐
│ Step 4: Pack FP8 Bits                                                       │
│   FP8 = (sign << 7) | (exp << 3) | mant                                     │
│                                                                              │
│   Example: 1.0                                                              │
│     FP8 = (0 << 7) | (7 << 3) | 0 = 0b00111000 = 0x38                       │
└─────────────────────────────────────────────────────────────────────────────┘

                                       ↓

┌─────────────────────────────────────────────────────────────────────────────┐
│                         FP8 E4M3 Format (8 bits)                             │
├─────┬───────────────┬───────────────────────────────────────────────────────┤
│  S  │  Exp (4 bits) │     Mantissa (3 bits)                                 │
│ 1bit│   Bias = 7    │                                                       │
└─────┴───────────────┴───────────────────────────────────────────────────────┘
   7        6-3                    2-0

Example: 1.0 = 0 0111 000
         Sign=0, Exp=7, Mant=0 → (-1)^0 × 2^(7-7) × 1.0 = 1.0


╔══════════════════════════════════════════════════════════════════════════════╗
║                        Special Cases Handling                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. Overflow (value > 448 or value < -448)                                   │
│    → Saturate to max FP8: 0x7E (448.0) or 0xFE (-448.0)                     │
│                                                                              │
│    Example: 500.0                                                           │
│      → exp_fp8 would be > 15 (max)                                          │
│      → Clamp to 0x7E = 0 1111 110 = 448.0                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. Underflow (value < 2^-9)                                                 │
│    → Return zero: 0x00 or 0x80                                              │
│                                                                              │
│    Example: 0.0001 (too small for FP8)                                      │
│      → exp_fp8 < -3 (below denormal range)                                  │
│      → Return 0x00                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. Denormal (2^-9 ≤ value < 2^-6)                                           │
│    → Set exp = 0, shift mantissa                                            │
│                                                                              │
│    Example: 0.001953125 (2^-9)                                              │
│      → exp_fp8 = -9 + 7 = -2 (negative, so denormal)                        │
│      → Shift mantissa right: mant = 0b001                                   │
│      → FP8 = 0 0000 001 = 0x01                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. NaN / Infinity                                                           │
│    → Convert to FP8 NaN: 0x7F (positive) or 0xFF (negative)                 │
│                                                                              │
│    Example: NaN                                                             │
│      → FP32 exp = 255 (special)                                             │
│      → FP8 = 0x7F (NaN representation in E4M3)                              │
└─────────────────────────────────────────────────────────────────────────────┘

├──────────────┼──────────────┼─────────────────────────────────────────────┤
│  +0.0        │    0x00      │  0 0000 000  (all zeros)                    │

│  +2.0        │    0x40      │  0 1000 000  (exp=8, mant=0)                │

╔══════════════════════════════════════════════════════════════════════════════╗
║                     Vectorized Kernel Processing                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

Each GPU thread processes 4 elements for memory coalescing:

Input (FP32):  [1.0,  2.0,  -3.0,  448.0]  (16 bytes)
                 ↓     ↓      ↓       ↓
              float4 load (coalesced)
                 ↓     ↓      ↓       ↓
Convert:     fp32_to_fp8_e4m3_scalar() × 4
                 ↓     ↓      ↓       ↓
FP8 bytes:   [0x38, 0x40, 0xC0, 0x7E]  (4 bytes)
                 ↓     ↓      ↓       ↓
           Pack into uint32 = 0x7EC0_4038
                        ↓
             uint32 store (coalesced)

Memory bandwidth improvement: 4x (fewer transactions)


╔══════════════════════════════════════════════════════════════════════════════╗
║                       Kernel Launch Configuration                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

For array size N:

threads_per_block = 256
blocks_per_grid   = (N + 256*4 - 1) / (256*4)

Each thread processes 4 elements, so:
  - Total threads needed: N/4
  - Threads per block: 256
  - Blocks needed: ceil((N/4) / 256) = ceil(N / 1024)

Example: N = 1024 elements
  blocks = (1024 + 1023) / 1024 = 1 block
  threads per block = 256 threads
  Total threads = 256 (each processes 4 elements)
  Elements processed = 256 × 4 = 1024 ✅

│ FP8 E4M3 Format Summary                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 8 bits total: 1 sign + 4 exponent + 3 mantissa                            │
│ • Exponent bias: 7                                                          │
│ • Range: [0.001953125, 448] (includes denormals)                            │
│ • Normal range: [0.015625, 448]                                             │
│ • Denormal range: [0.001953125, 0.015625)                                   │
│ • No infinity (uses max exponent for NaN)                                   │
│ • Precision: ~2-3 decimal digits (~6% relative error)                       │
